# epub2silero

Скрипт превращает книгу EPUB в аудиокнигу: по одному файлу MP3 (или M4A, WAV) на главу. Озвучивает локально голосами Silero TTS. Видеокарта не нужна.

Окружение целиком собирает [uv](https://docs.astral.sh/uv/): сам скачивает нужную версию Python, PyTorch, NumPy и ffmpeg в изолированное окружение. На компьютере заранее не нужно ничего, кроме самого uv. Список зависимостей записан в начале `epub2silero.py`, отдельного `requirements.txt` нет.

## 1. Установка uv

Это единственное, что ставится вручную.

**Windows** (в PowerShell):

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

или через winget:

```
winget install --id=astral-sh.uv -e
```

**macOS:**

```
brew install uv
```

**macOS и Linux** без Homebrew:

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

После установки **закройте и снова откройте терминал** и проверьте:

```
uv --version
```

Ставить Python отдельно не нужно: если подходящего нет, uv скачает свой и не тронет системный.

## 2. Первый запуск

Положите `epub2silero.py` в любую папку и откройте в ней терминал.

Сначала посмотрите, как книга разобьётся на главы. Звук при этом не создаётся:

```
uv run epub2silero.py "C:\Книги\книга.epub" --list
```

Если разбиение устраивает, запустите ту же команду без `--list`:

```
uv run epub2silero.py "C:\Книги\книга.epub"
```

Аудиофайлы появятся в папке `audiobooks` рядом со скриптом, в подпапке с именем файла книги: для `книга.epub` это `audiobooks/книга`. Чтобы сохранить их в другое место, укажите папку вторым аргументом:

```
uv run epub2silero.py "C:\Книги\книга.epub" "C:\Аудио\Книга"
```

При самом первом запуске uv создаст окружение и скачает Python и пакеты, это несколько сотен мегабайт и пара минут. Затем скрипт скачает модель Silero и положит её в папку `models` рядом с собой (файл `models/v5_5_ru.pt`). Последующие запуски стартуют сразу: окружение и модель уже на месте.

Пути с пробелами берите в кавычки. Русские буквы в путях допустимы. На macOS и Linux пути пишутся как обычно: `~/Книги/книга.epub`.

Совет для первого раза: поставьте в начале скрипта `ONLY_CHAPTERS = "1"`, чтобы озвучить одну главу, послушать голос и увидеть скорость. После каждой главы скрипт печатает, сколько звука получилось и за какое время.

### Прерывание и продолжение

Озвучку можно остановить в любой момент клавишами Ctrl+C. Чтобы продолжить, запустите ту же команду ещё раз: готовые главы будут пропущены, а прерванная начнётся заново.

## 3. Видеокарта NVIDIA (необязательно)

Silero и на процессоре работает быстрее реального времени, так что обычно это не нужно. Если всё же хотите использовать видеокарту:

1. В начале `epub2silero.py`, в блоке `# /// script`, поменяйте две строки:

   ```
   # sources = { torch = [{ index = "pytorch" }] }
   ```

   ```
   # url = "https://download.pytorch.org/whl/cu128"
   ```

   То есть уберите из `sources` условие `marker` и замените в адресе `cpu` на `cu128`. Сборка `cu128` нужна для карт RTX 50-й серии и подходит для более старых.

2. В настройках поставьте `DEVICE = "cuda"`.
3. Запустите как обычно. uv заметит изменения в заголовке и сам пересоберёт окружение; torch с CUDA весит несколько гигабайт.

## 4. Настройки

Все настройки — константы в начале `epub2silero.py`, их можно менять в любом текстовом редакторе. Основные:

| Настройка           | Что делает                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------- |
| `SPEAKER`           | голос: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`                                           |
| `OUTPUT_FORMAT`     | `mp3`, `m4a` или `wav`                                                                         |
| `BITRATE`           | качество MP3 и M4A, например `96k` или `128k`                                                  |
| `NUM_THREADS`       | потоки процессора; больше 4–6 обычно не ускоряет                                               |
| `SPLIT_MODE`        | как делить на главы: `auto`, `toc` (оглавление), `headings` (заголовки), `files` (файлы книги) |
| `TOC_MAX_DEPTH`     | сколько уровней оглавления учитывать, например `1` — только части                              |
| `ONLY_CHAPTERS`     | озвучить часть глав, например `"1-3,7"`                                                        |
| `MIN_CHAPTER_CHARS` | короче этого куски приклеиваются к следующей главе                                             |
| `PAUSE_*`           | паузы между абзацами, главами, заголовками                                                     |
| `LATIN`             | латиница: `translit` — читать транслитерацией, `drop` — пропускать                             |
| `SKIP_FOOTNOTES`    | не читать сноски                                                                               |
| `FFMPEG`            | путь к своему ffmpeg; по умолчанию берётся ffmpeg из окружения uv                              |

## 5. Перенос на другой компьютер

Достаточно скопировать `epub2silero.py`, поставить uv и запустить. Окружение на новом компьютере соберётся само; копировать его не нужно и нельзя.

Чтобы на всех компьютерах ставились одни и те же версии пакетов, один раз зафиксируйте их:

```
uv lock --script epub2silero.py
```

Рядом появится файл `epub2silero.py.lock`; переносите его вместе со скриптом, и `uv run` будет ставить ровно эти версии.

### Компьютер без интернета

Первый запуск должен пройти с интернетом: uv скачивает Python и пакеты. Модель можно скачать заранее на другом компьютере по ссылке из `MODEL_URL` в начале скрипта и положить в папку `models` рядом с `epub2silero.py`. После первого запуска интернет больше не нужен.

## Где лежит окружение и как его удалить

uv хранит окружение в своём кэше, а не в папке со скриптом. Удалить всё скачанное (Python, torch и прочее) можно командой:

```
uv cache clean
```

При следующем запуске окружение соберётся заново. Модель `v5_5_ru.pt` лежит в папке `models` рядом со скриптом, её удаляйте вручную.

## Если что-то не работает

| Сообщение или симптом                                | Что делать                                                                                                                      |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `uv` не найден после установки                       | Откройте новое окно терминала. Если не помогло, перезайдите в систему.                                                          |
| PowerShell пишет, что выполнение сценариев отключено | Устанавливайте uv именно командой из шага 1, она обходит запрет. Сам `uv run` от этой настройки не зависит.                     |
| Ошибка при скачивании пакетов                        | Проверьте интернет, VPN и антивирус: uv должен достучаться до `pypi.org`, а на Linux ещё до `download.pytorch.org`.             |
| `Не удалось скачать модель`                          | Сервер модели недоступен из вашей сети. Скачайте файл по ссылке из сообщения браузером и положите туда, куда указано.           |
| `Модель не смогла озвучить пробную фразу`            | Проверьте `SAMPLE_RATE` (8000, 24000 или 48000). Для моделей старше v5 оставьте в `TTS_OPTIONS` только `put_accent` и `put_yo`. |
| Главы разбиты неудачно                               | Посмотрите `--list` и попробуйте другой `SPLIT_MODE` или `TOC_MAX_DEPTH`.                                                       |
| Озвучка медленная                                    | Поиграйте `NUM_THREADS` (обычно лучше всего 4) и закройте тяжёлые программы.                                                    |
| Что-то сломалось после изменения заголовка           | `uv cache clean` и снова `uv run`.                                                                                              |

## Ограничения

- Книги с DRM-защитой не читаются.
- Числа читаются количественными в именительном падеже: «в 1941 году» прозвучит как «в тысяча девятьсот сорок один году».
- Латиница читается грубой транслитерацией.
- Модели Silero распространяются под некоммерческой лицензией: для личного пользования подходят, для продажи аудиокниг — нет.
